# XRechnung Viewer

JavaFX-Komponente zur übersichtlichen Darstellung von XRechnungen
(Syntax: UN/CEFACT CII) mit einer kleinen Demo-Anwendung.

## Module
- `invoice-view`: wiederverwendbare Visualisierungskomponente
- `invoice-view-demo`: Beispielanwendung (Datei auswählen und anzeigen)

## Voraussetzungen
- Java 17
- Maven
- OpenJFX 17.x
